# Accessible Contact Form

A responsive, accessible contact form demo built with HTML, CSS, and vanilla JavaScript.

## Features

- Required and optional fields, including a contact-method radio group and interest checkboxes
- Live field validation with helpful error messages
- Phone-number cleanup and validation for 10-digit Indian mobile numbers
- Accessible labels, validation announcements, and keyboard focus handling
- Submission confirmation with a summary of the entered information
- Responsive layout and reduced-motion support

## Run locally

Open `index.html` in a browser. No build tools or dependencies are required.

> **Demo only:** The form does not send information to a server. Submitted values are shown only in the browser.
